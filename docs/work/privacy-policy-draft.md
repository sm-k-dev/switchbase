# SwitchBase 개인정보 처리방침 (초안)

> 상태: **초안. 게시 전 사람이 확인해야 합니다.** `[결정 필요]` 항목은 채워야 게시할 수 있습니다.
> 기준: 현재 코드(회원·평가·후기·빌드·컬렉션·신고·탈퇴)에서 실제로 저장하는 항목만 적었습니다.

## 1. 총칙

SwitchBase(이하 "서비스")는 기계식 키보드 스위치 정보와 이용자의 체감 평가를 모으는 커뮤니티입니다.
서비스는 개인정보를 최소한으로 모으고, 필요한 기간만 보관합니다.

운영자: `[결정 필요: 운영자 이름 또는 개인 운영자 표기]`
문의: `[결정 필요: 문의 이메일 또는 문의 방법]`
시행일: `[결정 필요: 게시 날짜]`

## 2. 수집하는 항목

| 구분 | 항목 | 언제 | 필수 여부 |
|---|---|---|---|
| 회원가입 | 이메일, 닉네임, 비밀번호(암호화 저장) | 가입할 때 | 필수 |
| 이메일 인증 | 인증 토큰(해시로만 저장) | 가입·인증 메일 재발송 때 | 필수 |
| 체감 평가 | 평가 점수와 선택 항목, 사용한 빌드 여부, 개조 태그 | 평가를 등록할 때 | 선택(평가 기능 사용 시) |
| 후기 | 후기 본문, 추천 대상 | 후기를 쓸 때 | 선택 |
| 빌드 | 키보드 구성(하우징·보강판·마운트·키캡), 메모, 이름 | 빌드를 등록할 때 | 선택 |
| 컬렉션 | 즐겨찾기·보유·써봤음 표시와 공개 설정 | 토글을 누를 때 | 선택 |
| 도움됨 | 다른 회원 후기에 누른 도움됨 기록 | 도움됨을 누를 때 | 선택 |
| 신고 | 신고 대상, 사유, 메모, 신고자 | 신고할 때 | 선택 |

서비스는 아래 정보를 저장하지 않습니다.
- 실명, 전화번호, 주소, 생년월일
- 접속 IP 주소를 기록하는 로그 (현재 구현에 없음. 로그 설정을 바꾸면 이 항목을 고쳐야 합니다)
- 결제 정보 (유료 기능이 없음)

## 3. 수집 목적

- 회원 식별, 로그인, 이메일 인증
- 스위치 체감 평가와 후기, 빌드 정보의 표시와 집계
- 신고 처리와 커뮤니티 운영
- 탈퇴 처리와 재가입 제한

## 4. 보관 기간과 파기

| 항목 | 보관 기간 |
|---|---|
| 회원 정보 (이메일, 비밀번호 해시) | 탈퇴 즉시 삭제. 이메일과 비밀번호 해시는 탈퇴 시점에 바로 지웁니다. |
| 재가입 제한 기록 | 탈퇴 후 30일. 이메일은 HMAC 해시로만 보관하며 원문은 저장하지 않습니다. |
| 이메일 인증 토큰 | 발급 후 24시간. 해시로만 보관합니다. |
| 평가·후기·빌드 | 탈퇴 후 30일 동안 목록에 보이고, 이후 목록과 집계에서 빠지며 매일 완전 삭제합니다. |
| 컬렉션, 도움됨 표시 | 탈퇴 즉시 삭제합니다. |
| 신고 기록 | `[결정 필요: 보관 기간. 예: 처리 후 1년 등]`. 신고자는 탈퇴 시 연결이 끊기고 "탈퇴한 회원"으로 표시됩니다. |
| 위키 수정 기록 | 탈퇴 후에도 남습니다. 수정자는 "탈퇴한 회원"으로 표시됩니다. |

회원이 직접 지운 평가·후기·빌드는 지우는 즉시 목록에서 빠지고, 지운 날부터 30일 뒤 완전히 삭제됩니다.

## 5. 탈퇴

- 마이페이지의 탈퇴 메뉴에서 "탈퇴"를 입력하면 탈퇴합니다.
- 탈퇴하면 이 이메일로 로그인할 수 없고, 같은 이메일로는 30일 동안 다시 가입할 수 없습니다.
- 탈퇴 후 30일이 지나면 개인이 쓴 평가·후기·빌드는 완전히 지워집니다.

## 6. 제3자 제공과 위탁

- 서비스는 개인정보를 제3자에게 팔거나 넘기지 않습니다.
- 이메일 인증 메일 발송: `[결정 필요: SMTP 발송 서비스 이름. 위탁 업체를 밝혀야 합니다.]`
- 화면 스크립트(htmx)를 jsDelivr CDN(`cdn.jsdelivr.net`)에서 불러옵니다. 이때 브라우저의 IP 주소가 CDN에 전달될 수 있습니다.

## 7. 쿠키

- 로그인 상태를 유지하기 위해 세션 쿠키를 사용합니다. 이 쿠키는 로그인 상태 유지에만 쓰이며, 광고나 추적에는 쓰지 않습니다.
- 브라우저 설정에서 쿠키를 막을 수 있지만, 그러면 로그인과 평가 기능을 쓸 수 없습니다.

## 8. 이용자의 권리

- 이용자는 자신의 정보를 열람하고, 수정하고, 탈퇴로 삭제를 요청할 수 있습니다.
- 열람과 수정은 로그인 후 마이페이지에서 할 수 있습니다.
- 탈퇴 외에 개인정보 삭제가 필요하면 문의로 요청할 수 있습니다. `[결정 필요: 처리 기한. 예: 10일 이내]`

## 9. 보호 조치

- 비밀번호는 해시(암호화)로만 저장합니다.
- 이메일 인증 토큰과 재가입 제한 값은 해시로 저장합니다.
- 운영 서버와 데이터베이스는 외부에서 직접 접근할 수 없도록 설정합니다. `[결정 필요: 실제 운영 구성에 맞게 확인]`

## 10. 방침의 변경

- 방침이 바뀌면 시행일 7일 전에 서비스 공지로 알립니다. `[결정 필요: 공지 방법]`

## 작성자 메모 (게시 전에 지울 것)

- 코드 기준 확인 사항: `Retention.PERIOD = 30일`, `TOKEN_TTL = 24시간`, 탈퇴 시 이메일·비밀번호 해시를 NULL로 바꾸고 재가입 차단 해시만 남김(`WithdrawalService`, `Member.withdraw`).
- IP 로그는 현재 없습니다. 나중에 접근 로그를 켜면 2절과 4절을 고쳐야 합니다.
- 3~4절 보관 기간과 신고 기록 기간, 운영자 정보는 사람이 정해야 합니다.
- 실제 게시 전 법률 검토를 권합니다. 이 초안은 법률 자문이 아닙니다.
